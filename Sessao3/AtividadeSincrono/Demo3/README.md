# Laboratório Síncrono — OA3
## Combinar dados (Combine Files).

### Atividade 03
Nesta atividade utilizamos os arquivos que se encontram na pasta [Contabilidade](./Contabilidade/):
* [LancamentosContabilidade2018](./Contabilidade/LancamentosContabilidade2018.csv)
* [LancamentosContabilidade2019](./Contabilidade/LancamentosContabilidade2019.csv)
* [LancamentoContabilidade2020](./Contabilidade/LancamentoContabilidade2020.csv)

Inicialmente guardamos somente o ficheiro **"LancamentoContabilidade2018.csv"** na pasta **"Contabilidade"**. Obtivemos os dados da pasta contabilidade com a configuração adequada para mais tarde aplicar as transformações necessárias. Mais tarde, depois de criar alguns relatórios, testamos a adição dos novos documentos **"LancamentosContabilidade2019.csv"** e **"LancamentoContabilidade2020.csv"** e atualizamos os relatórios. 

Desta forma verificamos que a interligação e ingestão automática dos ficheiros funciona de forma adequada e elimina trabalho repetitivo e moroso.

As evidências podem ser encontradas na [**pasta evidências**](./evidencias/)
