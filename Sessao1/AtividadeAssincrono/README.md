### Criação do relatório no Power BI Desktop utilizando um documento excel como base.
Esta atividade consiste em importar dados de um arquivo excel, transformar os dados abreviados para os nomes completos e fazer a tipagem das datas.

Os relatórios criados foram:
1. Cartão com número de pessoas na lista;
2. Gráfico de barras com número de pessoas por área;
